# Yuting Wu — personal website

A lightweight academic personal homepage for GitHub Pages, with responsive layout and light/dark themes. Layout inspired by https://dfguooo.github.io/; all biography and academic content is intentionally left as placeholders.

## Editing

- Edit `index.html` to fill in the biography, news, publications, projects, teaching and services.
- Replace the portrait placeholder with your own photo when ready.
- Adjust colors and layout in `style.css`.

## GitHub Pages

Repository name: `yutingwu-ntuiot.github.io`.

In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**, then save.

Expected URL after publishing: https://yutingwu-ntuiot.github.io/
